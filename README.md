# GitCharm for VSCode / Qoder

在 VSCode/Qoder 中复刻 IntelliJ IDEA 的 Git UI 和工作流。

**当前版本**: v0.0.1 - GitCharm 首个正式发布版本

## 环境要求

- **VSCode**: ≥ 1.95.0（需要 `repo.getRefs()` API 支持）
- **Qoder**: 最新版本
- **Git**: ≥ 2.0.0
- **vscode.git 扩展**: 已启用（内置扩展，默认开启）

## 功能特性

### 核心功能

- **三栏式 Git 日志面板**：分支树 / 提交列表（含筛选器）/ 提交详情
- **分支管理**：新建、检出、重命名、删除、合并、变基、推送、拉取、获取
- **提交操作**：查看差异、Cherry-Pick、交互式变基、压缩提交、删除提交、编辑提交信息、重置到指定提交
- **Blame 注解**：行内显示每行的最后修改者与日期，悬停查看完整提交信息
- **文件对比**：右键文件与其他分支对比，或查看单次提交引入的差异

### 性能优化

- **秒开体验**：三阶段渐进式加载（骨架屏 → 分支 → 提交），启动速度 <10ms
- **智能缓存**：工作区持久化缓存分支信息，重启后立即可用
- **双平台支持**：自动检测 Qoder 或 VSCode，选择合适的缓存路径

### UI 体验

- **丝滑圆润**：统一圆角 6-12px，平滑过渡动画，悬停微动效
- **时间显示**：当天提交相对时间（"X 小时前"），非当天完整日期（YYYY-MM-DD）
- **自定义主题**：所有对话框和提示适配 VSCode 主题色
- **入场动画**：淡入、滑入、缩放等流畅过渡效果

### 安全与可靠性

- **变基前检查**：自动检测工作区未提交更改，避免变基失败
- **智能菜单**：当前分支右键菜单移除不适用操作（检出、合并、变基）
- **精确搜索**：Blame 点击提交时自动使用 git 命令精确匹配 hash
- **友好提示**：搜索未找到时显示 12 位短哈希，提高辨识度

### UI 体验升级

- **Canvas 图谱渲染**：Git 提交图改用 Canvas API 绘制，像素级精确对齐，消除圆点与线条分离问题
- **高 DPI 支持**：自动适配 Retina/4K 屏幕，图谱清晰锐利无模糊
- **性能优化**：大量提交时图谱渲染更流畅，Canvas 比 SVG/DOM 高效数倍

## 安装

### 方法一：VSIX 安装

1. 下载 `.vsix` 安装包
2. 在 VSCode/Qoder 中执行命令：`Extensions: Install from VSIX...`
3. 选择下载的 `git-charm-0.0.1.vsix` 文件
4. 重新加载窗口

### 方法二：市场安装

在扩展市场搜索 "GitCharm" 并安装

## 使用方法

1. 打开一个 Git 仓库项目
2. 左侧活动栏点击 **GitCharm** 图标（或从命令面板搜索 `GitCharm: Open Log`）
3. 在三栏面板中浏览提交历史、切换分支、执行 Git 操作

### 常用操作

| 操作 | 方式 |
|------|------|
| 切换分支 | 左侧分支树右键 → 检出 |
| 查看提交详情 | 点击中间栏提交行 |
| 对比文件 | 编辑器右键 → "与其他分支对比此文件" |
| 显示 Blame | 编辑器右键 → "显示提交信息" 或行号区域点击 |
| 删除最后提交 | 提交行右键 → "删除提交"（仅 HEAD） |
| 编辑最后提交信息 | 提交行右键 → "编辑提交信息"（仅 HEAD） |
| 交互式变基 | 选中多个提交 → 右键 → "交互式变基" |
| 压缩提交 | 选中多个提交 → 右键 → "压缩提交" |
| 推送分支 | 分支右键 → 推送（支持分页查看提交） |
| 拉取分支 | 分支右键 → 拉取（智能刷新） |

### 高级功能

#### 推送对话框

- 初始显示前 20 条待推送提交
- 点击"加载更多"按钮查看全部提交
- 鼠标悬停在提交上查看完整信息
- 支持普通推送和强制推送

#### 变基/合并操作

- 顶部状态栏显示进行中的操作
- 提供"继续"和"终止"按钮
- 解决冲突时自动打开 SCM 视图
- 操作完成后状态栏自动隐藏

#### 缓存管理

**查看缓存文件：**
```bash
# Qoder
ls .qoder/.idea-git-cache/branches.json

# VSCode
ls .vscode/.idea-git-cache/branches.json
```

**清理缓存：**
- 自动：执行 Git 操作（pull/push/checkout 等）后自动清理
- 手动：删除缓存文件即可

**配置缓存：**

在设置中搜索 `idea-git.cache` 可配置：
- `idea-git.cache.enabled`: 启用/禁用缓存（默认开启）
- `idea-git.cache.ttlMinutes`: 缓存有效期（1-60 分钟，默认 5 分钟）
